# owl 0.6.0 计划

> 起草 2026-06-06（0.5.0 公开发版后）。0.5.0 = per-profile 隔离 + 免密快切（详见
> `docs/history/P5-d-shipped.md`）。0.6.0 的范围以**「先整理、再加功能」**为原则：开发期累积了
> 大量计划外需求与临时取舍，先做一次系统性审视清理，再推进 feature backlog。
> 本文是活页路线，每个 Phase 开工前另拉独立子设计文档（沿用 P5-d 习惯）。

## Step 0（首步，必做）：系统性项目审视 / 整理

**目标**：不改变任何用户可见功能的前提下，降低代码与文档的熵——清冗余、清死代码、局部小重构、
非功能优化。开发期（P5-a → 0.5.0）攒下的临时取舍在此一次性收口。

**做法**：先**审视产出一份发现清单**（按下列维度扫描，标 risk/收益），与用户过一遍 triage，
再分小批执行（每批 `just check` + `just test` 全绿 + 独立 commit）。**不夹带功能改动**。

审视维度：

1. **死代码 / 暂留 exports**
   - `@owl/core` 暂留导出 `clearSkybridgeAuth` / `writeSkybridgeConfig` / `requireAuth`（Phase 10 记「GUI main + 测试仍用，Phase 11+ 顺手清」）——核实当前真实消费者，无用则删。
   - daemon `SKYBRIDGE_NOT_INSTALLED` 防御分支（npm dep 装上后不可达）——保留 or 删，定性。
   - 历史 migration / 兼容分支（如 legacy 顶层 `[auth]` 视图、0.3.0 rebuild 残留）是否仍需要。
   - 全仓 `rg` 找未被引用的 export / 文件 / 常量。
2. **biome warnings 清理**：当前 `just check` 有 ~53 个 biome warning（`noNonNullAssertion` 为主，`!` → `?.` 或显式 narrow）。逐个评估，能消则消（注意 watchdog/sse-bridge 等热点文件）。目标：warning 清零或明确豁免。
3. **文件体积**：按 CLAUDE.md 规约扫 >500 行（建议拆）/ >800 行（强制拆）的源文件，列拆分候选（如 `sync-auth.ts` / `manual.ts` / 大测试文件）。
4. **重复建模 / 逻辑**：config / types / 错误码 / payload parser 是否有可抽取的重复；shared 类型边界是否仍清晰。
5. **测试冗余**：重复 fixture、过时 e2e 注释、可合并的 case；gated e2e 与单测覆盖是否重叠。
6. **文档冗余**：`docs/plans/` 下已 ship 的子设计是否都在 `docs/history/*-shipped.md` 有索引；过时引用（如 `COEDIT_PLAN.md`、§8 作废的 p3-plan）清理或标注。
7. **依赖审计**：`package.json` 未用依赖（如 CLI 标注 commander+pkg 但实际 tsup 打包）、版本对齐、`pnpm` workspace 一致性。
8. **TODO / FIXME / XXX sweep**：全仓扫注释里的待办，归类到 backlog 或就地解决。

**产出**：`docs/plans/2026-06-XX-0.6.0-cleanup-findings.md`（发现清单 + triage 结论），然后按批执行。

## Step 1+：feature backlog（0.5.0 之外，设计稿 §11）

Step 0 清理告一段落后排期（顺序待定，按价值/依赖）：

- **W7 冲突双向可见 + 手动解决/合并**：赢方也可见；「用本地版本覆盖」（把 `local_payload` 当新编辑重 apply 走 `updateNote` 拿新 LWW 戳）；`@codemirror/merge` 2-way 合并编辑器（依赖已装）；`conflict_record` 加 counter 列（W3 §4.1 留账）。
- **W11 附件同步传播**：0.5.0 是 local-only（不丢 attachmentRefs），0.6 加传播通道（独立 attachment 存储/传输策略，开工前单拉 design）。
- **跨 profile 统一视图** / **跨账号导入**（A→B：快照业务表 + 在 B 生成全新 create ops，绝不搬 synced outbox）/ **local→非空账号导入**（0.5.0 只支持认领空账号 D10b）。
- **`resetAllStores(epoch)` 免闪烁切换**：替代当前 profile 切换的整窗 `location.reload()`（每次切换 bump `profileEpoch`，各 zustand store 订阅清空+重拉）。
- **TLS / 反代**：0.5.0 是明文 HTTP + 安全组锁源 IP；正式公网部署加 Caddy/nginx 反代 + TLS（`skybridge/docs/deploy/ubuntu-baota.md` §11 占位）。
- **真·24h soak**：Phase 20 T4 降范围跳过，云已拆需重部署后跑。
- **P8 非核心池**（届时定 scope）：tray 图标 / 图片粘贴 / FIM 补全 / `[[` note-link / 编辑器正文 slash command / `owl doctor --recover` / `@owl/core` 公开发布 等。
