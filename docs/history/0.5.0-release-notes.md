# owl 0.5.0 — per-profile 账号隔离 + 免密快切 (macOS arm64)

> 本文件是 0.5.0 的用户可见 release notes 草稿，供 Phase 23 作 GitHub Release body。
> macOS arm64 only。数据目录 `~/orpheus-aviary-nest/owl/` 不动，可直接覆盖装。

0.4.2 → 0.5.0 是 owl 同步能力的一次大跨越。0.4.2 只是"早期可用"，0.5.0 把整套
**多账号 per-profile 隔离 + 免密快切**，外加一系列可靠性加固落地——这是同步功能
**首个推荐试用**的版本（仍需自部署 skybridge server）。

> 升级：已装 0.4.x 的直接覆盖装；首次启动会**自动一次性**把旧的单账号布局
> （顶层 `[auth]` + `owl/owl.db`）迁成 per-profile 布局（`profiles/<id>/owl.db` +
> `[profiles.<id>]`），非破坏、原库保留为本地工作区。

## 核心：per-profile 账号隔离

- 每个登录账号拥有**独立**的 `profiles/<id>/owl.db`，互不串味。
- **本地工作区（local）= 原地 `owl/owl.db`**，账号同步**永不写本地库**——离线/不登录照常用。
- 多账号可共存，各看各的笔记 / 文件夹 / 标签 / 提醒。
- profile 锚点是 skybridge **server_id**（可迁移带走，换 server url 不丢工作区）。

## 免密快切

- 侧栏同步状态栏下拉，**一键切换**账号 / 本地，无需重输密码。
- 背后是 refresh-token 流（**带轮换**，旧 token 即作废防重放）；切换保留 token，仅
  完全登出 / 移除设备才吊销。

## 账号 / 设备管理（设置 → 同步）

- GUI 内登录 / 登出（终端 `owl sync login` 已退役，改由 GUI 完成）。
- **设备列表** + 移除其它设备（吊销远端）。
- **已保存账号**列表 + 删除某账号的本地副本（强二次确认）。
- 手动同步按钮（兼当重连入口）。

## 登录体验

- **认领空账号**：本地有笔记又登录了一个空账号时，弹框让你选择是否把本地笔记并入该账号。
- **已登录态直接添加新账号**：新账号成为活跃账号，旧账号留在"已保存"可免密快切回去。

## 可靠性加固

- **W3 时间戳归一化（HLC-lite）**：用 server 归一化 offset + per-device counter 做 LWW，
  **错钟设备不再成为黑洞**（不会静默覆盖别人的新编辑）。
- **SSE idle watchdog**：补上"半开/下行假死"——连接还在但 server 静默停推时，60s 内
  识别并自动重连（此前只能靠手动同步兜底）。
- **单实例锁**：重复启动只聚焦已有窗口，不再开第二个实例。
- **切换并发安全**：单实例锁 + 切换互斥 + 跨进程 switch lockfile 三层正交，CLI direct
  写入也尊重切换锁，杜绝切到换库中途的半态库。

## 顺手 UX

- 待办页按**笔记创建顺序**排序（新→旧），脏编辑旧笔记不再浮顶。
- 冲突页：**复制输方全文** + **打开笔记**（跳编辑器）+ 长内容块限高滚动。

## 已知限制与使用指引

- **附件 local-only**：0.5.0 暂不传播附件（笔记正文照常同步，round-trip 不丢
  attachmentRefs），附件跨设备传播留 0.6。
- **提醒仅活跃账号触发**：非当前账号的提醒不会响（单活跃账号设计）。
- **从备份恢复的预期行为**：用旧备份覆盖后、期间在别处改过的同名笔记，会显示
  「冲突（远端胜出）」需你 review 后忽略——这是**恢复场景的预期安全行为、零丢失**，
  不是 bug（远端为准 + 冲突可见）。
- **冲突当前仅"忽略"**：双向解决 / 合并编辑留 0.6。
- **自部署 skybridge server 当前为明文 HTTP**：公网部署须用安全组锁源 IP；TLS / 反向
  代理留 0.6。

## 安装 / 升级

### GUI

1. GitHub Releases 下载 `Owl-0.5.0-arm64.dmg`，拖入"应用程序"。
2. 首次打开（ad-hoc 签名）：右键 Owl.app → 打开 → 弹窗点"打开"；或系统设置 → 隐私与
   安全性 → "仍要打开"。之后不再询问。

> 已装 0.4.x 的：直接覆盖装，数据目录不动；首启自动跑 schema 迁移 + per-profile 布局迁移。

### CLI

```bash
npm i -g @orpheus-aviary/owl-cli
```

0.5.0：`owl sync login` 退役（改由 GUI 登录）；`--db` 文案更新；CLI direct 写入尊重
GUI 切换锁。

### 自部署 skybridge server（可选 / 高阶）

需 **0.1.4**（server_id / server 时间 / refresh 轮换 / device revoke）：

```bash
npm i -g @orpheus-aviary/skybridge-server
```

⚠️ 0.1.x 无内置 TLS，公网部署须套反向代理或锁源 IP。
