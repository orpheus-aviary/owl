# owl 0.6.0 — 同步状态可视化 + 无缝切账号 + 冲突手动解决 (macOS arm64)

> 用户可见 release notes 草稿，供 GitHub Release body。macOS arm64 only。
> 数据目录 `~/orpheus-aviary-nest/owl/` 不动，可直接覆盖装。

0.5.0 → 0.6.0 聚焦**本地体验打磨 + 一个安全加固**：同步从「能用」升到「看得见、切得顺、
冲突解得开」，同时给本地 daemon 加上了鉴权（**破坏性变更，必读**）。

## ⚠️ 破坏性变更（必读）：本地 daemon 现在需要鉴权

关闭的是一个安全洞——恶意网页可裸打 `127.0.0.1` 上的本地 daemon（CSRF / 读泄露）。修法是
让所有合法客户端带一个本地 token。带来的升级影响：

- 本地 daemon 除 `GET /status` 外，所有请求现在都要 `Authorization: Bearer <token>`（token 自动
  生成，落 `~/orpheus-aviary-nest/owl/daemon-token`；**GUI / CLI 自动读取并携带，正常使用无感**）。
- **升级后请重启一次**：退出 Owl 再打开（GUI 会拉起带 token 的新 daemon）。若你手动跑过 daemon，
  先停掉旧的。
- **CLI 必须一起升级到 0.6.0**——旧 CLI 不带 token，打不了新 daemon。
- **第三方 / 脚本直连本地 API** 的：需读 `daemon-token` 文件并带 Bearer 头；`browser → 本地 daemon`
  不再支持（改用云端版）。

## 同步状态看得见

- 侧栏同步状态栏升级为**三态**：同步中 / 已同步 / 不可达，判据修正为「已注册账号」而非「配置里有
  server url」。
- SSE 断线**精确重探**（exactly-once），不再依赖模糊的错误恢复；连接生命周期更稳。

## 切账号无缝

- 切换账号 / 本地**不再整页刷新**——告别切换时的白屏闪烁，用会话世代（session-epoch）在原地重建。
- **脏标签保护**：当前有未保存编辑时切换账号 / 登出，会先提示「保存 / 放弃 / 取消」，不再静默丢改动。

## 冲突能手动解决了（补上 0.5.0 的坑）

- 0.5.0 冲突页只能「采用远端」。0.6.0 补齐：**「用本地版本覆盖」** + **「手动处理」两栏合并编辑器**
  （`@codemirror/merge`），冲突从「只能认输」变成「可覆盖 / 可逐行合并」。

## 稳定性 / 内部（行为保持）

- SSE 改 fetch 式；平台适配层抽离；API client 抽成 `@orpheus-aviary/owl-shared`；大文件全部拆分、
  复杂度告警清零。桌面行为不变，为后续网页 / 移动端复用打底。

## 仍留后续

- **附件跨设备传播 / TLS 反代 / 多设备 GA** — 随后续版本。
- **网页 / 移动端**：云端版 **owl-server** 以 npm 单独发布（`@orpheus-aviary/owl-server`），本桌面版
  不含；两者共享同一套 skybridge 账号。

## 安装 / 升级

### GUI

1. GitHub Releases 下载 `Owl-0.6.0-arm64.dmg`，拖入「应用程序」。
2. 首次打开（ad-hoc 签名）：右键 Owl.app → 打开 → 弹窗点「打开」；或系统设置 → 隐私与安全性 →
   「仍要打开」。之后不再询问。
3. ⚠️ **已装 0.5.x 的**：覆盖装后**退出 Owl 再打开一次**，确保带 token 的新 daemon 生效（见破坏性变更）。
   数据目录不动，首启自动跑 schema 迁移。

### CLI

```bash
npm i -g @orpheus-aviary/owl-cli    # 升级到 0.6.0，务必和 GUI 一起升
```
